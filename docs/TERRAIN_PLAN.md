# Terrain visualization plan

The team specification supplies the fixed site IDs, DE421 mean-Earth frame, reference radius, metric coordinates, and 2 m observer. The handoff supplies product scope and milestones. The browser viewer now opens a continuous 87°S–90°S polar cap, streams native 5 m mosaic detail near the view center, and offers direct zoom to the two fixed study coordinates. Passes 1 and 2 below record the initial local terrain prototype and its reusable assets.

| Pass | Work | Acceptance |
| --- | --- | --- |
| 1 · Implemented | Read Site01/Site04 rasters; match the reference observer elevations; export site manifest and both local GLBs. | Pixel center conventions checked; fixed locations preserved; one input meter maps to one GLB unit; visual gaps preserved. |
| 2 · Implemented | Site switching, tabletop, desktop surface preview, shaded relief/elevation/wireframe, compass, observer and 10 m axis references. | North −Z, east +X, up +Y; no vertical exaggeration. A site switch changes metadata and geometry together. A view switch preserves site and observer. |
| 3 · Next data handoff | Obtain independent numerical horizons for both sites. Use local 5 m data within 5 km, regional 80 m data to 100 km and 240 m data to 400 km after checking overlap registration. Target 0.25° spacing and compare 100/200/400 km and finer bearings. | Each artifact keys the exact observer, records resolution, coverage, sources and convergence; gaps remain unknown. Keep signed angles. Local visual mesh never supplies authoritative horizon values. |
| 4 · Next browser feature | Render the horizon profile and optional distance-independent skyline using valid bins, breaking lines at missing bearings. Add schematic Sun/Earth directions and a UTC scrubber based on the team's time-tagged data. | True north alignment in both modes, no interpolation across coverage gaps, no fabricated markers or visibility. Consume visibility flags from the science workstream; use the same observer/time in both views. |
| 5 · Comparison and polish | Add synchronized A/B terrain and horizon comparison, consistent elevation color range option, coverage/provenance details, optional visual shadows, wider context and levels of detail if profiling justifies them. | Same UTC and equipment assumptions; never rank incomplete science as measured. Check phone touch and keyboard controls, view framing, mesh memory and loading, and compare landmark orientation to the source. Keep illustrative shadows distinct from computed observer status. |

For the eventual team integration, use the supplied 2027 scenario domain and January default, then bind the viewer to the shared scenario state. Swap desktop controls for Quest controls only when requested; keep the data and underlying metric models shared.
