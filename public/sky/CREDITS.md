# Sky view textures

`earth_atmos_2048.jpg`, `earth_lights_2048.png` and `earth_clouds_1024.png` come from the three.js r160 example
assets (`examples/textures/planets/`, MIT-licensed repository). Their original imagery source is not documented
there. Before a public release, replace them with NASA Visible Earth "Blue Marble" (day) and "Black Marble"
(night lights) images (https://visibleearth.nasa.gov), which are public domain, keeping the same file names
and the same equirectangular layout (longitude -180 at the left edge).
